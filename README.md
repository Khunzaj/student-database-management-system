# Student Database Management System

A simple web-based Student Database Management System developed using Python and Django.

## Features

- Dashboard
- Add Student
- View All Students
- Search Students
- View Student Details
- Edit Student
- Delete Student
- Django Admin Panel

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub

## Student Information

The system stores:

- Name
- Email
- Phone Number
- Course
- Semester

## CRUD Operations

- Create – Add Student
- Read – View Student
- Update – Edit Student
- Delete – Delete Student
